INSTALACIONES PARA LA BASE DE DATOS Y LA API
============================================

PostgreSQL 18.6
---------------

Finalidad: almacenar usuarios, cámaras, estados operativos, sesiones e historiales
compartidos. Está instalado como servicio automático postgresql-x64-18.

Programa: C:\Program Files\PostgreSQL\18
Datos persistentes: C:\Program Files\PostgreSQL\18\data
Puerto local: 5432
Interfaces autorizadas: 127.0.0.1 y ::1

No debe publicarse el puerto 5432. Los respaldos se guardarán fuera del directorio
activo de PostgreSQL y fuera de Git.

Dependencias Node.js del backend
--------------------------------

- fastify: servidor HTTP y enrutamiento de la API.
- @fastify/cookie: futuras cookies HttpOnly.
- pg: pool y consultas parametrizadas para PostgreSQL.
- zod: validación de configuración y entradas.
- dotenv: carga exclusiva de .env.backend.local.
- tsx: ejecución local de TypeScript.
- @types/pg: tipos TypeScript del controlador PostgreSQL.

Ninguna contraseña se incluye en este documento ni en archivos rastreados por Git.
